  • 지자체 공공 소식만 provider를 새로 쓴다 — 성남시 · 성남신문 두 개를 붙였다

문제 · 동기 호출로 서버가 멈춤
async 함수 안에서 동기 httpx.post를 부르니 이벤트 루프가 통째로 막혔다. 추천 한 건이 도는 동안 다른 모든 요청이 대기했다. → asyncio.to_thread로 분리.
문제 · “작업을 찾을 수 없어요”
작업을 프로세스 메모리에만 두어 --reload가 걸릴 때마다 사라졌다. → recommend_jobs 테이블에 영속화하고 메모리는 캐시로만 사용.
문제 · “생성이 중단됐어요”
멈춤 판정이 너무 빨라 정상 작업을 죽였다. LLM이 실제로 80~130초 걸린다는 걸 측정한 뒤 7분 유예 + 프론트 자동 재시도로 고쳤다.

상세 URL 패턴을 추측해서 만들었는데 실제 경로가 달랐다. → 목록 페이지의 스크립트에서 진짜 경로를 찾아 고치고, 이미 저장된 20건도 함께 갱신.

배치가 ‘이번 주 월요일부터’ 7일을 만들어, 주 후반엔 지난 날짜만 보였다. 예보는 미래만 오니 날씨가 붙을 자리도 없었다. → 오늘부터 7일로 변경.
지도 워터마크
정적 지도의 로고가 내용을 가렸다. 잘라내는 건 이용약관 위반이라 잘라내지 않고 레이아웃으로 피했다.
스케줄러가 아예 안 떠 있었다
브리핑이 며칠씩 비었다. 시각 설정이 아니라 잡을 물고 있을 프로세스가 없었다 — compose가 Dockerfile 없이 build를 가리켰고, API 쪽 스케줄러 플래그는 기본값이 꺼짐이었다.
앱 로그가 어디에도 안 찍혔다
uvicorn은 자기 로거만 설정한다. 앱 로거에 핸들러가 없어 위 사실을 아무도 볼 수 없었다. 로그를 켜자 그 자리에서 드러났다.
로그인은 됐는데 튕겼다
주소로 바로 들어가면 피드로 되돌아갔다. 설정을 다 읽기 전에 로딩을 끝냈던 것. 캡처 스크립트가 URL을 검증하다가 발견했다.
